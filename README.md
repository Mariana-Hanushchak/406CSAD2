# Лабораторна робота №1 — Проєктування AI-агента для автоматизації розробки та CI/CD

- **Репозиторій:** `406CSAD2`
- **Студент:** Ганущак Мар'яна (група КІ-406)
- **Варіант:** 2 (Python 3, `venv` + скрипт запуску, `pytest`)

## Опис проєкту

Проєкт демонструє створення спеціалізованого AI-агента (`build-engineer`) із модульними навичками (`skills`), іменованими командами (`prompts`) та оркестратором (`init`) для автоматизованої генерації, ізольованого налаштування віртуального середовища Python (`venv`), модульного тестування за допомогою `pytest` і кросплатформної перевірки в GitHub Actions (Ubuntu, Windows, macOS).

## Як запустити AI-агента та проєкт

1. Відкрийте репозиторій у **Visual Studio Code** із активованим **GitHub Copilot**.
2. Оберіть агента **`build-engineer`** (`.github/agents/build-engineer.agent.md`) та виконайте оркестратор `/init` або окремі команди (`/git-init`, `/create-project`, `/create-build`, `/create-actions`, `/check`).
3. Для локального запуску проєкту та тестів:
   - **Windows:** `.\scripts\ci.bat`
   - **Linux / macOS:** `chmod +x scripts/ci.sh && ./scripts/ci.sh`
